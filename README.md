# Терруары Сербии

Справочник по сербскому виноделию на русском языке. Одно издание — один файл
`index.html`, без сборки и без зависимостей: открывается двойным щелчком и
публикуется как есть.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | сама книга, издание 3-40 |
| `favicon.svg` | знак «срез» — иконка сайта |
| `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | растровые запасные иконки |

## Проверки

    python3 check.py index.html

Дубли `id`, битые `label for`, битые внутренние ссылки, полнота проводки
подсказок, изоляция глав и незакрытые теги, разорванные слова.

Сверка видимого текста с предыдущей версией — когда разметка меняется
механически, а текст меняться не должен:

    python3 check.py index.html --text-same-as старая-версия.html

Зависимостей нет, нужен только Python 3.

Чистый отчёт означает отсутствие механических дефектов и ничего больше.
Читать текст всё равно приходится.
