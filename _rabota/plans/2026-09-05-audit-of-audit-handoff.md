## Обязательная методология

- `supporting_source_ids` содержит только источники, прямо подтверждающие точную границу утверждения.
- Контекст, молчание и `no_relevant_material` относятся только к `checked_only_source_ids`.
- Оба массива ролей должны быть явно записаны в каждой новой review-строке, включая пустые массивы.
- Все Википедии считаются одной источниковой семьёй.
- Для каждого использования источника нужна обратная ссылка через `claim_ids`.
- Старые записи `sources.jsonl` неизменны по фактическим полям; допустимо дополнять только `claim_ids`.
- Поздний поиск должен быть настоящим и фиксировать дату поискового действия отдельно от даты доступа к источнику.
- Розничные, производительские и конкурсные источники использовать только в пределах их компетенции.
- Отсутствие сведений не является опровержением.
- Результат `исправлен` допустим только при реальном изменении исходного корпуса и точной трассировке полей в `changes`.
- `index.html` не изменять.
