# Словарь полей

Три таблицы, каждая в двух видах: `.jsonl` для скриптов, `.csv` для таблиц
и глаза. Содержимое одинаковое. Пересобираются из сырья одной командой:

    python3 _rabota/rejtingi/sobrat-tablicy.py
    python3 _rabota/rejtingi/proverit-dannye.py

**Руками таблицы не правятся.** Правится сырьё — `vivino-zapisi.jsonl`,
`kritiki-zapisi.jsonl`, `raion-hozyaistv.json`, `falstaff-zvezdy.json` —
и таблицы пересобираются.

---

## `hozyaistva` — хозяйства

| Поле | Что в нём |
|---|---|
| `hozyaistvo` | имя в том виде, в каком оно встречалось при сборе |
| `klyuch` | то же имя без регистра и диакритики; по нему сводить |
| `region` | виноградарский регион Сербии: `Vojvodina`, `Centralna Srbija`, `Kosovo i Metohija` |
| `rejon` | рејон по действующей рејонизацији, один из 22. Справочник — `rejony-vinogorja.json` |
| `vinogorje` | виногорје, одно из 77. Всегда принадлежит своему рејону |
| `rejon_istochnik` | откуда рејон: `mesto` — по городу хозяйства, это старше всего; `decanter`, `vivino`, `vinarijesrbije`, `falstaff` (через `+`, если сошлись несколько); `bolshinstvo` — источники разошлись, взято подавляющее; `ne_ustanovlen` |
| `region` без `rejon` | место известно грубо: Vivino дал имя старой рејонизације. Регион верен, рејон — один из перечисленных в `rejon_raznoglasie` |
| `rejon_raznoglasie` | если источники разошлись — что именно каждый говорил. Пусто, когда спора не было |
| `raion_knigi` | код главы книги: `fruska`, `subotica`, `banat`, `sumadija`, `morave`, `negotin`, `toplica`, `jugoistok`, `podunavlje`, `metohija`. `null` — район не установлен |
| `raion_istochnik` | откуда район: `kniga` — так решила книга; `raspolozhenie` — по расположению винодельни; `ne_ustanovlen` |
| `gde` | пояснение к расположению, если оно спорное |
| `v_knige` | названо ли хозяйство в книге |
| `vivino_slug` | адрес страницы хозяйства на Vivino |
| `falstaff_zvezd` | звёзды Falstaff, 1–5. `null` — в собранном куске списка не встретилось |
| `vin_v_dannyh` | сколько вин этого хозяйства в таблице `vina` |

## `vina` — вина

| Поле | Что в нём |
|---|---|
| `klyuch` | `хозяйство-вино` без регистра и диакритики. Ключ для `ocenki.klyuch_vina` |
| `hozyaistvo`, `vino` | имена как есть |
| `vivino_id` | числовой идентификатор Vivino, тот, что в адресе после `/w/`. `null` — не выяснен |
| `vivino_adres` | полный адрес страницы |
| `vivino_status` | `ocenka_est` — оценка показана; `malo_ocenok` — вино на Vivino есть, но оценки нет, отзывов слишком мало; `net_na_vivino` — вино известно только по оценке критика |
| `v_knige` | названо ли это вино в книге поимённо |
| `est_u_kritikov` | есть ли на него стобалльная оценка |

## `ocenki` — оценки, по строке на измерение

Длинный вид: одна строка — одно измерение одним источником. Оценка Vivino
и балл Falstaff лежат рядом, но не складываются: у каждой строки написано,
чья шкала и на какой выборке держится балл.

| Поле | Что в нём |
|---|---|
| `klyuch_vina` | ссылка на `vina.klyuch` |
| `hozyaistvo`, `vino` | повторены здесь же, чтобы таблицу можно было читать без соединения |
| `istochnik` | `vivino`, `falstaff`, `wine-searcher`, `vino.rs`, `tastings` |
| `shkala` | `5` у Vivino, `100` у критиков |
| `ball` | сама оценка |
| `vyborka` | число отзывов. Только у Vivino; у критиков всегда `null` |
| `vyborka_nizhnyaya_granica` | `true`, если число взято из профиля вкуса или из отдельного урожая: настоящее не меньше указанного |
| `god` | урожай. `null` у Vivino — там оценка по всем урожаям сразу |
| `ogovorka` | примечание, если при сборе была оговорка |
| `stranica` | откуда взято |
| `sobrano` | дата съёма. Оценки Vivino живые и меняются; без даты через год числа будут врать |

## `nagrady` — награды и места в категориях

Отдельная таблица, потому что награда — не балл. «Лучшее белое из местных
сортов 2025 года» и «92 балла Falstaff» устроены по-разному: у первого нет
шкалы, зато есть категория и год; у второго наоборот. Переводить одно
в другое нельзя.

| Поле | Что в нём |
|---|---|
| `klyuch_vina` | ссылка на `vina.klyuch`. Пусто, если награда досталась хозяйству целиком, а не вину |
| `hozyaistvo`, `vino` | кому досталось. `vino` пусто у наград хозяйству |
| `istochnik` | `vino.rs`, `decanter`, `awc-vienna` |
| `god` | год присуждения — не урожай |
| `kategoriya` | в какой категории. У vino.rs их 31–33, у Decanter это разряд медали |
| `mesto` | `1`…`5` — место в категории; `platina`, `zlato`, `srebro`, `bronza`, `best-in-show` — конкурсная медаль |
| `urozhaj` | год урожая вина |
| `stranica` | откуда взято |
| `sobrano` | дата съёма |

## Чего в таблицах нет

Сорта, цвет вина, урожай у записей Vivino, цена. При сборе через поиск это
не отдавалось. Сплошной сбор по API (`sobrat-rejtingi.py`) вернёт и их —
поля под них в `razobrat_vino` уже размечены.

## Как этим пользоваться

Пятёрки по районам считаются из `vivino-zapisi.jsonl` скриптом
`svesti-pyaterki.py`, оценки критиков — `svesti-kritikov.py`. Для всего
остального удобнее `ocenki.csv`: там всё в одном длинном виде.

Три вещи, о которых стоит помнить при любом счёте:

1. **Шкалы не смешивать.** 4,2 у Vivino и 92 у Falstaff — не одно и то же
   в разных единицах. Vivino сам сопоставляет свои 4,0 примерно с 90 баллами
   критиков, но это грубое соответствие, а не перевод.
2. **Оценку без выборки не ранжировать.** У 202 оценок Vivino из 317 число
   отзывов неизвестно; сортировать их по баллу — это ровно та ошибка, ради
   которой правило отбора и заведено.
3. **`rejon` и `raion_knigi` — разные сетки, а не два имени одного.**
   Рејон — действующее сербское деление, 22 штуки; глава книги — авторское,
   их десять. Одна глава может покрывать несколько рејонов, а целые рејоны
   в книгу не попасть. Сверка — в начале `po-rejonima.md`.
4. **`rejon_istochnik` важнее самого `rejon`.** `mesto` значит, что рејон
   выведен по городу и надёжен; `bolshinstvo` — что источники спорили.
5. **Награды не суммировать с оценками.** У вина может быть и балл, и место
   в категории; это два разных высказывания о нём, а не два слагаемых.
