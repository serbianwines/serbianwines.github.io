# Терруары Сербии

Справочник по сербскому виноделию на русском языке. Одно издание — один файл
`index.html`, без сборки и без зависимостей: открывается двойным щелчком и
публикуется как есть.

## Проверки

Две, и обе нужны: первая стережёт разметку, вторая — поведение.

    python3 _rabota/check.py index.html

Дубли `id`, битые `label for`, битые внутренние ссылки, полнота проводки
подсказок, изоляция глав и незакрытые теги, разорванные слова.

Сверка видимого текста с предыдущей версией — когда разметка меняется
механически, а текст меняться не должен:

    python3 _rabota/check.py index.html --text-same-as старая-версия.html

Зависимостей нет, нужен только Python 3.

Вторая открывает книгу в настоящем браузере и проверяет, что она делает:

    python3 _rabota/proverka-knigi.py

Двадцать одна глава и приложение раскрываются и закрываются, все 64 подсказки
открываются и закрываются, содержание не отстаёт от книги, стрелка и адрес
ведут куда надо, карта называет районы, шрифты применяются, тема идёт за
системной и слушается переключателя, книга работает без сценариев, печатается
раскрытой, не едет вбок на узком экране и открывается без сети.

Нужен playwright: `pip install playwright && playwright install chromium`.
Сервер для проверки скрипт поднимает сам — служебный сценарий на `file://`
не работает.

Чистый отчёт означает отсутствие механических дефектов и ничего больше.
Читать текст всё равно приходится.

## Издание

Публикуется через GitHub Pages из корня основной ветки. Номер издания живёт
в истории коммитов и метках релизов, а не в имени файла.

По адресам сайта открывается только книга: `index.html`, иконки и `og.png`.
Рабочие файлы лежат в каталоге `_rabota`: каталоги с подчёркиванием в начале
имени не публикуются, так что новый файл достаточно положить туда. Четыре
файла, которым место в корне, — `README.md`, `CLAUDE.md`, `logo.svg`,
`avatar-512.png` — перечислены в `_config.yml` поимённо.
